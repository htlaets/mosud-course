# Практическая работа № 6 — вариант 3

Задача: найти заказы, у которых сумма `price` по позициям выше средней суммы заказа.

Основное решение использует коррелированный скалярный подзапрос и `EXISTS`. Альтернативное решение сначала агрегирует позиции заказа в CTE `order_totals`, затем один раз вычисляет среднее. Результаты сравниваются `EXCEPT` в обе стороны. Отдельно показаны операторы `ANY` и `ALL`.

Скалярный подзапрос обязан вернуть не более одной строки, поэтому внутри него используется агрегат `SUM`. `EXISTS` удобен там, где важен сам факт существования связанной строки, а не её значение.
