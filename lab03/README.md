# Практическая работа № 3 — вариант 3

## Реляционная алгебра

Исходное отношение:

`products(product_id, product_category_name, product_weight_g, product_photos_qty, ...)`

Искомое выражение:

`π product_id, category, weight_g, photos_qty
 (σ 1000 ≤ weight_g ≤ 5000 ∧ photos_qty ≥ 3 (products))`

С переименованием атрибутов можно записать:

`ρ(category ← product_category_name,
   weight_g ← product_weight_g,
   photos_qty ← product_photos_qty)(...)`

Разбиение предиката эквивалентно:

`σ photos_qty ≥ 3 (σ 1000 ≤ weight_g ≤ 5000 (products))`

## Вывод

Две последовательные выборки дают тот же результат, что и одна выборка с конъюнкцией условий. Порядок независимых фильтров можно менять, поскольку выборки с условиями, соединёнными `AND`, коммутируют. Ранняя проекция уменьшает число столбцов в промежуточном отношении. В основной проекции присутствует `product_id`, являющийся ключом таблицы `products`, поэтому полные строки результата не дублируются; без `product_id` дубликаты уже возможны.
