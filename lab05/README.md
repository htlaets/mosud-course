# Практическая работа № 5 — вариант 3

Множество обязательных штатов:

`S = {BA, PE, CE}`

Нужно найти категории товаров, встречавшиеся в доставленных заказах покупателей **каждого** из этих штатов.

Реализованы три эквивалентных варианта реляционного деления:

1. двойной `NOT EXISTS`;
2. `GROUP BY / HAVING COUNT(DISTINCT customer_state)`;
3. `EXCEPT` внутри `NOT EXISTS`.

Эквивалентность проверяется оператором `EXCEPT` в обе стороны. Для пустого `target_states` двойной `NOT EXISTS` возвращает все ненулевые категории: универсальное утверждение над пустым множеством считается истинным.
