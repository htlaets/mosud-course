# Практическая работа № 7

Вариантов в методичке нет.

В работе показана трёхзначная логика SQL: сравнение с `NULL` через `=` или `<>` даёт `UNKNOWN`, поэтому используются `IS NULL` и `IS NOT NULL`. `COUNT(*)` считает все строки, а `COUNT(column)` — только строки с ненулевым значением этого столбца.

`NOT IN` становится опасным, если подзапрос содержит `NULL`; для антисоединения надёжнее `NOT EXISTS`. Условие на правую таблицу в `ON` у `LEFT JOIN` сохраняет строки левой таблицы, а аналогичное условие в `WHERE` может удалить их.

Естественный `NULL`: отсутствие `review_comment_message` — пользователь мог поставить оценку без текста. Более подозрительный с точки зрения качества данных `NULL`: отсутствие `product_category_name`, поскольку товар обычно должен иметь категорию.
